# Abrir MongoDB Compass

MongoDB Compass quedo instalado en:

```text
/Applications/MongoDB Compass.app
```

Cadena de conexion para la practica:

```text
mongodb://127.0.0.1:37017
```

Si Compass no conecta, primero inicia MongoDB con Docker:

```bash
cd /PATH/BaseDatosMACDIA2026/BasedeDatosII/Unidad1/PracticaMongoDB
docker start mongodb-uasd
```

Para detenerlo:

```bash
docker stop mongodb-uasd
```
