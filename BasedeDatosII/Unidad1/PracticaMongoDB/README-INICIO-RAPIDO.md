## Opcion A: MongoDB Compass

1. Abrir MongoDB Compass.
2. Conectar con `mongodb://127.0.0.1:37017`.
3. Seguir el archivo `40225495809_Concepcion_PracticaMongoDB_Compass.md`.
4. Guardar capturas en la carpeta `evidencias`.
5. Completar el informe `40225495809_Concepcion_PracticaMongoDB_Informe.md`.

## Opcion B: Docker y mongosh

Con Docker Desktop abierto, iniciar el contenedor si esta detenido:

```bash
docker start mongodb-uasd
```

Ejecutar la practica completa:

```bash
./run-practica-mongodb-docker.sh
```
