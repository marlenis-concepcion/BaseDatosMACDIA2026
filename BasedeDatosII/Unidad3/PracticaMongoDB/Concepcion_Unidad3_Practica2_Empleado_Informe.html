Aplicar técnicas de importación e inserción masiva de documentos en MongoDB, comprendiendo el comportamiento de _id, insertMany() y las inserciones ordenadas.

  • Colección: empleados.

Comandos de ejecución

cd /PATH/BaseDatosMACDIA2026/BasedeDatosII/Unidad3/PracticaMongoDB

Lo solicitado y cómo se cumplió

Requisito Cumplimiento
Script de importación. Se creó run-unidad3-practica2-docker.sh, que importa dataset/empleados.json mediante mongoimport.
Sentencias de inserción. Se incluyeron insertOne() e insertMany() en Concepcion_Unidad3_Practica2_Empleado.js.
Evidencia del contenido final. El script imprime el conteo final y los documentos de la colección ordenados por _id.
Captura del conflicto de _id. Se provoca un duplicado de _id con ordered:true y se captura el error reportado por MongoDB.
Operadores de comparación y lógicos. Se usaron $gt, $lte, $in, $ne, $and, $or, $nor y $not.

Resumen de operaciones realizadas

  • Importación: carga inicial de empleados con mongoimport.
  • Inserción individual: uso de insertOne() para agregar un empleado adicional.
  • Inserción masiva ordenada: uso de insertMany() con ordered:true para demostrar que la operación se detiene ante un _id duplicado.
  • Inserción masiva no ordenada: uso de insertMany() con ordered:false para demostrar que MongoDB continúa con documentos válidos.
  • Consultas: filtros con operadores de comparación y operadores lógicos.

Archivo: run-unidad3-practica2-docker.sh

Este script automatiza la ejecución. Verifica que el contenedor de MongoDB esté activo, copia el dataset y el script JavaScript al contenedor, importa los empleados con mongoimport y luego ejecuta las sentencias con mongosh.

#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
DATASET_FILE="$SCRIPT_DIR/dataset/empleados.json"
SCRIPT_FILE="$SCRIPT_DIR/Concepcion_Unidad3_Practica2_Empleado.js"
CONTAINER_NAME="mongodb-uasd"
CONTAINER_DATASET="/tmp/unidad3-empleados.json"
CONTAINER_SCRIPT="/tmp/unidad3-practica2-empleado.js"

if ! docker ps --format '{{.Names}}' | grep -qx "$CONTAINER_NAME"; then
  echo "MongoDB Docker no esta corriendo."
  echo "Primero ejecuta:"
  echo "  docker start $CONTAINER_NAME"
  exit 1
fi

echo "============================================================"
echo " Unidad 3 - Practica No. 2 - Empleado"
echo " Estudiante: Marlenis Concepcion"
echo " Docente: Bismark Montero"
echo " Conexion: mongodb://127.0.0.1:*******"
echo "============================================================"
echo

docker cp "$DATASET_FILE" "$CONTAINER_NAME:$CONTAINER_DATASET"
docker cp "$SCRIPT_FILE" "$CONTAINER_NAME:$CONTAINER_SCRIPT"

echo "Importando dataset con mongoimport..."
docker exec "$CONTAINER_NAME" mongoimport \
  --db empresa \
  --collection empleados \
  --drop \
  --jsonArray \
  --file "$CONTAINER_DATASET"

echo
echo "Ejecutando sentencias de insercion y consultas..."
docker exec "$CONTAINER_NAME" mongosh --quiet "$CONTAINER_SCRIPT"

echo
echo "============================================================"
echo " Practica ejecutada. Ya puedes tomar captura de esta consola."
echo " En Compass conecta con: mongodb://127.0.0.1:*******"
echo " Base de datos: empresa"
echo " Coleccion: empleados"
echo "============================================================"

printjson(db.empleados.find({ $nor: [{ activo: true }, { departamento: "Tecnologia" }] }, { _id: 1, nombre: 1, departamento: 1, activo: 1 }).toArray());

print("$not: salarios que no son mayores que 90000");
printjson(db.empleados.find({ salario: { $not: { $gt: 90000 } } }, { _id: 1, nombre: 1, salario: 1 }).toArray());

print("\n6. Evidencia del contenido final de la coleccion");
print("Total final:");
printjson(db.empleados.countDocuments());
printjson(db.empleados.find({}, { _id: 1, nombre: 1, departamento: 1, salario: 1, activo: 1 }).sort({ _id: 1 }).toArray());

print("\nPractica finalizada. Se evidencio mongoimport, insertOne, insertMany, ordered:true, ordered:false y consultas con operadores.");

Practica No. 2 - Empleado

Aplicar tecnicas de importacion e insercion masiva de documentos en MongoDB, comprendiendo el comportamiento de _id, insertMany() y las inserciones ordenadas.

Entorno:
- MongoDB ejecutado con Docker.

- Conexion local: mongodb://127.0.0.1:*******.

- Coleccion: empleados.

Archivos principales:

6. Consultas con operadores de comparacion: $gt, $lte, $in y $ne.
7. Consultas con operadores logicos: $and, $or, $nor y $not.

Resultado esperado:
La coleccion conserva los empleados importados y los documentos validos insertados. El conflicto de _id queda registrado como evidencia de que MongoDB no permite claves _id duplicadas.
