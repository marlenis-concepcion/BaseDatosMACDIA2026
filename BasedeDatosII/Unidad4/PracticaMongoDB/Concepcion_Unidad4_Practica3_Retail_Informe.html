Explicación de las consultas

  1. $exists y $type: valida que exista el documento embebido envio y que total sea numérico.
  2. $regex: filtra nombres de clientes que comienzan con patrones específicos.
  3. $elemMatch: exige que un mismo elemento del array productos cumpla categoría y precio.
  4. $all y $size: verifica valores requeridos dentro de un array y cantidad exacta de elementos.
  5. $expr, $mod y $and: combina condiciones, valida divisibilidad y compara el campo total contra una expresión basada en cliente.edad.

// Universidad Autonoma de Santo Domingo
// Base de Datos II - Unidad 4
// Practica No. 3 - Retail
// Objetivo: construir consultas MongoDB sobre estructuras JSON complejas,
// combinando filtros, documentos embebidos, arrays y operadores.
// Estudiante: Marlenis Concepcion
// Docente: Bismark Montero

use("retail");

print("\n============================================================");
print("Practica No. 3 - Retail");
print("Base de datos: retail");
print("Coleccion: ventas");
print("============================================================\n");

print("Dataset cargado:");
printjson(db.ventas.find({}, { _id: 1, tienda: 1, canal: 1, total: 1, estado: 1 }).sort({ _id: 1 }).toArray());

print("\nConsulta 1 - $exists y $type");
print("Ventas que tienen documento envio y cuyo total es numerico.");
printjson(
  db.ventas.find(
    {
      envio: { $exists: true, $type: "object" },
      total: { $type: "number" }
    },
    { _id: 1, tienda: 1, total: 1, envio: 1 }
  ).sort({ _id: 1 }).toArray()
);

print("\nConsulta 2 - $regex sobre documento embebido");
print("Clientes cuyo nombre comienza con A, C o R.");
printjson(
  db.ventas.find(
    { "cliente.nombre": { $regex: "^(Ana|Carlos|Rosa)", $options: "i" } },
    { _id: 1, "cliente.nombre": 1, "cliente.ciudad": 1, total: 1 }
  ).sort({ _id: 1 }).toArray()
);

print("\nConsulta 3 - $elemMatch en array de documentos");
print("Ventas con un producto de tecnologia cuyo precio es mayor o igual a 14000.");
printjson(
  db.ventas.find(
    {
      productos: {
        $elemMatch: {
          categoria: "tecnologia",
          precio: { $gte: 14000 }
        }
      }
    },
    { _id: 1, tienda: 1, productos: 1, total: 1 }
  ).sort({ _id: 1 }).toArray()
);

print("\nConsulta 4 - $all y $size en arrays");
print("Ventas que usaron tarjeta y puntos, y tienen exactamente dos cupones.");
printjson(
  db.ventas.find(
    {
      pagos: { $all: ["tarjeta", "puntos"] },
      cupones: { $size: 2 }
    },
    { _id: 1, cliente: 1, pagos: 1, cupones: 1 }
  ).sort({ _id: 1 }).toArray()
);

print("\nConsulta 5 - $expr, $mod, $and y documento anidado");
print("Ventas pagadas, de cliente premium, con total par y total mayor que edad del cliente multiplicada por 300.");
printjson(
  db.ventas.find(
    {
      $and: [
        { estado: "pagada" },
        { "cliente.tipo": "premium" },
        { total: { $mod: [2, 0] } },
        { $expr: { $gt: ["$total", { $multiply: ["$cliente.edad", 300] }] } }
      ]
    },
    { _id: 1, "cliente.nombre": 1, "cliente.tipo": 1, "cliente.edad": 1, total: 1, estado: 1 }
  ).sort({ _id: 1 }).toArray()
);

print("\nResumen final");
print("Total de ventas en la coleccion:");
printjson(db.ventas.countDocuments());
print("Se ejecutaron cinco consultas avanzadas sobre documentos embebidos y arrays.");

Practica No. 3 - Retail

Objetivo:
Construir consultas MongoDB sobre estructuras JSON complejas, combinando filtros, documentos embebidos, arrays y operadores de comparacion y logicos.

Entorno:
- MongoDB ejecutado con Docker.
- Contenedor: mongodb-uasd.
- Conexion local: mongodb://127.0.0.1:*******.
- Base de datos: retail.
- Coleccion: ventas.

Comando para ejecutar:

docker start mongodb-uasd
cd /PATH/BaseDatosMACDIA2026/BasedeDatosII/Unidad4/PracticaMongoDB
./run-unidad4-practica3-docker.sh

Cinco consultas incluidas:
1. $exists y $type: validar existencia y tipo del documento envio y del total.
2. $regex: buscar nombres de clientes que comienzan con Ana, Carlos o Rosa.
3. $elemMatch: buscar ventas con producto de tecnologia y precio mayor o igual a 14000.
4. $all y $size: buscar ventas con pagos especificos y cantidad exacta de cupones.
5. $expr, $mod y $and: comparar campos y expresiones, validar total par y combinar condiciones.

Resultado esperado:
Cada consulta imprime el resultado obtenido y permite evidenciar el operador utilizado sobre documentos anidados y arrays.

docker exec mongodb-uasd mongosh --quiet --eval 'use("retail"); db.ventas.find({envio:{$exists:true,$type:"object"}, total:{$type:"number"}}, {_id:1, tienda:1, total:1, envio:1}).sort({_id:1}).toArray()'

Parte 5: Consulta 2 con $regex

docker exec mongodb-uasd mongosh --quiet --eval 'use("retail"); db.ventas.find({"cliente.nombre":{$regex:"^(Ana|Carlos|Rosa)",$options:"i"}}, {_id:1, "cliente.nombre":1, "cliente.ciudad":1, total:1}).sort({_id:1}).toArray()'

Parte 6: Consultas 3 y 4 con arrays

docker exec mongodb-uasd mongosh --quiet --eval 'use("retail"); db.ventas.find({productos:{$elemMatch:{categoria:"tecnologia", precio:{$gte:14000}}}}, {_id:1, tienda:1, productos:1, total:1}).sort({_id:1}).toArray()'

docker exec mongodb-uasd mongosh --quiet --eval 'use("retail"); db.ventas.find({pagos:{$all:["tarjeta","puntos"]}, cupones:{$size:2}}, {_id:1, cliente:1, pagos:1, cupones:1}).sort({_id:1}).toArray()'

Parte 7: Consulta 5 y resumen final
