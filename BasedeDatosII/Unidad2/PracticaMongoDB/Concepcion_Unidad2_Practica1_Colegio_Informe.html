Requisito Cumplimiento
Aplicar operaciones CRUD. Se insertaron, consultaron, actualizaron y eliminaron documentos en MongoDB.
Usar documentos anidados. Se modelaron los campos direccion y tutor como documentos embebidos.
Usar arreglos anidados. Se usaron arreglos simples como actividades y arreglos de documentos como asignaturas.

Resumen de operaciones realizadas

  • Create: inserción de tres estudiantes originales y un estudiante adicional para demostrar eliminación.

  • Update: actualización del estado activo, adición de una actividad y cambio de calificación dentro del arreglo asignaturas.
  • Delete: eliminación únicamente del estudiante adicional, conservando los tres documentos originales.

Archivo: run-unidad2-practica1-docker.sh

Este script automatiza la ejecución de la práctica usando Docker. Verifica que el contenedor mongodb-uasd esté activo, copia el archivo JavaScript al contenedor y lo ejecuta con mongosh. También imprime en la consola los datos del entorno usado, incluyendo la conexión local, la base de datos y la colección, para que la salida pueda tomarse como evidencia.

#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
SCRIPT_FILE="$SCRIPT_DIR/Concepcion_Unidad2_Practica1_Colegio.js"
CONTAINER_NAME="mongodb-uasd"
CONTAINER_SCRIPT="/tmp/unidad2-practica1-colegio.js"

if ! docker ps --format '{{.Names}}' | grep -qx "$CONTAINER_NAME"; then
  echo "MongoDB Docker no esta corriendo."
  echo "Primero ejecuta:"
  echo "  docker start $CONTAINER_NAME"
  exit 1
fi

echo "============================================================"
echo " Unidad 2 - Practica No. 1 - Colegio"
echo " Estudiante: Marlenis Concepcion"
echo " Docente: Bismark Montero"
echo " Conexion: mongodb://127.0.0.1:37017"
echo "============================================================"
echo

docker cp "$SCRIPT_FILE" "$CONTAINER_NAME:$CONTAINER_SCRIPT"
docker exec "$CONTAINER_NAME" mongosh --quiet "$CONTAINER_SCRIPT"

echo
echo "============================================================"
echo " Practica ejecutada. Ya puedes tomar captura de esta consola."
echo " En Compass conecta con: mongodb://127.0.0.1:37017"
echo " Base de datos: colegio"
echo " Coleccion: estudiantes"
echo "============================================================"
